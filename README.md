# JimWashkau Radio

Original music by Jim Washkau. Public audio hosting for https://www.jimwashkau.com/radio.

The station follows the ordered playlist in playlist.json, looping from its fixed UTC epoch. Durations are measured from the MP3 files. The website pins a repository commit so future uploads do not change existing playback unexpectedly.
